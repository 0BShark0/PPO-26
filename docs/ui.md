# ЛР5. Интерфейс финансового директора

Веб-приложение (монолит, `findirector/ui/web.py`). Три страницы, без регистрации.

| Страница | Ввод | Действия | Результат | Ошибки |
| --- | --- | --- | --- | --- |
| **Планы** `/` | — | «Создать план», ссылка на план | Список сохранённых планов | — |
| **План** `/plan`, `/plan?id=…` | Название, начальные деньги, Q/P/V/F/A для месяцев 1–3. Суммы можно вводить как `30000`, `30 000`, `30000,50` | «Рассчитать» — прогноз без сохранения; «Сохранить» — запись в БД и возврат к плану | Таблица по месяцам (П-Ф2): выручка, маржинальный доход, расходы, прибыль, поступления, деньги на конец, задолженность; итоги П-Б7. У отрицательных денег подпись **«Не хватает денег»** | Красная рамка у поля, текст «Месяц 2, оплата сразу (A): процент оплаты должен быть целым от 0 до 100»; расчёт и сохранение не выполняются (П-Ф5). Несуществующий id — «План не найден» |
| **Сравнение** `/compare` | Два плана из выпадающих списков | «Сравнить» | Рядом: прибыль за 3 месяца, C3, D3, потребность в финансировании (П-Ф3) | «Выберите два плана» |

**П-Ф6.** Каждый расчёт — новый POST с текущими данными формы; сервер не хранит прошлых результатов.
При любом изменении поля (событие `input`/`change`) прежний прогноз или сравнение скрываются и
показывается подсказка «нажмите Рассчитать / Сравнить».

**ЛР5-А1.** Обработчики вызывают `PlanService.forecast / save / open_plan / list_plans / compare_saved`.
В UI нет формул: числа берутся из `MonthReport` и `PlanTotals`.
